# Брейкпоинты

Зафиксированы в `src/styles/grid.css`. Единственный брейкпоинт — `75rem` (1200px), округление от ширины Figma-фрейма (1280px). Отдельного мобильного/таблетного макета в Figma нет — поведение ниже брейкпоинта спроектировано самостоятельно, мобильно-первый подход (CLAUDE.md).

| Диапазон | Hero (`.heroGrid`) | Кейс (`.caseGrid`) |
|---|---|---|
| `< 1200px` (mobile-first по умолчанию) | 1 колонка, стек: приветствие → био → ссылки → аватар → копирайт | 1 колонка, стек: название → описание+метаданные → медиа |
| `≥ 1200px` (`min-width: 75rem`) | 3 равные колонки | 2 колонки `1fr 2fr` (текст / медиа) |

Страница кейса (`/work/:slug`) живёт на другом брейкпоинте — `50.625rem` (810px), том же, что у референса Framer. Её сетка и поля описаны в `docs/07-case-template.md`.

## Остальное поведение
- Курсор-кружок (`Cursor`) отключён на touch-устройствах (`pointer: coarse`) на всех брейкпоинтах
- `CaseMedia` сохраняет аспект 4:3 на всех ширинах (object-fit: cover)
- Паддинг страницы (`--page-pad`, 16px) одинаковый на всех брейкпоинтах — не меняется по ширине экрана
