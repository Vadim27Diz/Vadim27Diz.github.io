# Секции и их анимации

Главная страница — всего две секции, без Header/Footer/About/Contact: в Figma-каркасе всё содержимое «о себе» и контакты живут внутри Hero, а футера нет вовсе (страница зациклена, см. `01-brief.md`).

## Hero (`src/sections/Hero.tsx`)
- Контент из `src/content/profile.ts`: приветствие + иконка-стрелка, био, список ссылок (cv/telegram/linkedin/mail), аватар (контейнер, фото — TBD), копирайт
- Раскладка: 3 колонки на десктопе (`.heroGrid`) — приветствие / био+ссылки / аватар+копирайт; стек на мобильном
- Анимация при входе: нет (первый экран, видим сразу, без scroll-reveal)

## Projects / «Кейсы» (`src/sections/Projects.tsx`)
- Контент: кейсы из `src/content/projects.ts`, рендер через `ProjectCard`
- Раскладка каждой строки (`.caseGrid` в `ProjectCard`): название+описание+метаданные слева, медиа-контейнер (`CaseMedia`) справа; стек на мобильном
- Анимация: появление каждой строки по скроллу через `useScrollReveal` (GSAP ScrollTrigger), однократно
- Медиа: `CaseMedia` — контейнер 4:3 под фото или видео, формат/разрешение см. `02-design-tokens.md` и сообщение в чате при добавлении медиа
