# Правила анимаций

## Общий принцип
Простой и тихий стиль, как на референсе https://plyn.framer.website/piershy — минимум эффектов. Движение подчёркивает паузы и воздух на странице, а не привлекает внимание к себе: только `opacity`/`transform`, без ярких или сложных эффектов.

## Тайминги (из `src/styles/tokens.css`)
| Токен | Значение | Когда использовать |
|---|---|---|
| `--duration-fast` | `0.2s` | hover-реакции (ссылки, кнопки, курсор) |
| `--duration-base` | `0.4s` | появление элементов при скролле |
| `--duration-slow` | `0.8s` | переходы между страницами/крупными секциями |
| `--duration-ripple` | `1.12s` | смена темы (растущий круг от иконки переключателя) |

## Easing
`--ease-default`: `cubic-bezier(0.22, 1, 0.36, 1)` — мягкое замедление на выходе, единая кривая для всех анимаций (появление, hover, курсор). Отдельных кривых под разные эффекты не вводим.

## Появление по скроллу
- Через `useScrollReveal` (`src/hooks/useScrollReveal.ts`) — GSAP + ScrollTrigger, `start: "top 85%"`
- Только `opacity` + небольшой `translateY` (8–16px), без масштабирования и вращения
- Проигрывается один раз (`once: true`) — повторный вход в viewport анимацию не повторяет
- ScrollTrigger синхронизирован с Lenis через `gsap.ticker` в `useLenis.ts` — без этого скролл-анимации дёргаются

## Кастомный курсор
Повторяет поведение референса: курсор — круг, который следует за указателем и увеличивается при наведении на интерактивные элементы.

- Базовое состояние: небольшой круг (~8–12px), моноцветный (`--color-fg`)
- При ховере на интерактив (ссылки, карточки проектов, кнопки): круг увеличивается (~40–48px); системный курсор на этих зонах скрывается (`cursor: none`)
- Масштаб анимируется через `transform: scale()`, не через `width`/`height` — не триггерит layout
- Длительность — `--duration-fast`, easing — `--ease-default`
- Курсор следует за указателем с небольшим сглаживанием (lerp), а не мгновенно — за счёт этого ощущение мягкости
- На touch-устройствах кастомный курсор полностью отключён (скрыт; тап работает как обычно)

### Реализация
- Компонент `Cursor` (`src/components/Cursor.tsx`), подключён один раз в `App.tsx`
- Позиция — через `gsap.quickTo` по `x`/`y` (плавное сглаживание), состояние — через `ref`, без `setState` на каждый `pointermove`
- Увеличение — через CSS-класс `.hover` (transform: scale, транзишен на чистом CSS, не GSAP) при наведении на `[data-cursor="hover"]`
- Отключается на touch через `matchMedia("(pointer: coarse)")`

## Смена темы
При клике на иконку темы (`NavBar`/`CaseNavBar`, хук `useThemeIcon`) по экрану растёт круг от центра кнопки, раскрывающий уже переключённую тему поверх застывшего снимка старой — без плоской заливки и без «попа» в конце.

- Реализация — нативный View Transition API (`document.startViewTransition`) + `clip-path` на `::view-transition-new(root)` через Web Animations API (`src/hooks/themeRipple.ts`). Браузер сам снимает реальные снимки старой/новой страницы — под кругом настоящий контент, а не плоский цвет
- Стекинг и отключение дефолтного кросс-фейда псевдоэлементов — `src/styles/global.css` (`::view-transition-old/new(root)`)
- Длительность — `--duration-ripple`, easing — `--ease-default` (тот же, что у остальных анимаций сайта)
- Переключение темы (`data-theme`) происходит внутри `startViewTransition`-callback сразу, до анимации — круг раскрывает уже готовый результат, а не прячет резкий скачок
- При `prefers-reduced-motion: reduce` и в браузерах без View Transition API (Firefox) — тема переключается мгновенно, без анимации
