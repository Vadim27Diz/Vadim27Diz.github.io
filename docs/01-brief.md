# Бриф

## Имя / студия
Резников Вадим — продуктовый дизайнер. Личное портфолио, без студии/команды.

## Чем занимается
Продуктовый дизайн (UX/UI для цифровых продуктов) — от исследования до интерфейса. Сайт показывает кейсы, а не продаёт услуги: без форм «оставить заявку», без прайса.

## Структура сайта
Мультистраничный сайт, не one-page лендинг:

| Страница | Назначение |
|---|---|
| Главная | Имя/позиционирование, сетка проектов (`.grid` из `src/styles/grid.css`), переход на страницы кейсов |
| Страница кейса | Один проект: обложка, контекст/роль/процесс, результат, медиа, переход к следующему кейсу |

Список кейсов — TBD, заполняется в `src/content/projects.ts`.

## Настроение
Ультра-минимализм, по формулировке самого референса: «No clutter. No distractions. Your work is the statement.»
- Много воздуха, тонкие гаттеры (14px)
- Монохромная база (чёрный/белый/серый), акцент — только типографика и медиа проектов
- Спокойный, тихий темп — созерцательное портфолио, не агрессивный шоуофф

## Структурная особенность: без футера
У референса нет футера — страница воспринимается как зацикленная: нижняя точка не обрывается в футер, а возвращает к началу.

Для нашего сайта:
- Главная заканчивается последней секцией (About/Contact), без отдельного классического Footer-блока с колонками
- Возврат наверх — через зацикленный скролл или «вернуться наверх», решение фиксируется в `04-animations.md` / `03-sections.md` на этапе реализации
- Текущий компонент `src/components/Footer.tsx` нужно будет пересмотреть: либо убрать, либо оставить как минимальную петлю (имя/контакт/соцсети в одну строку, без сетки ссылок)
